# Verifica CF e P. IVA - supporto

Repository pubblico contenente esclusivamente le pagine richieste per assistenza, privacy e condizioni d’uso delle versioni iOS e Android di **Verifica CF e P. IVA**.

Il codice sorgente delle app è conservato in repository privati separati.

Versioni supportate: **iOS 1.0.1** e **Android 1.0.0**.
